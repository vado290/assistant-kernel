## Recovery and stopping

Before new-protocol adoption, a code-only rollback may restore the previous pointer
and guarded source delta if protected state remains compatible and no new business
facts would be lost. After a new-protocol Task or question exists, do not start the
0.27.2 controller on it: retain compatible readers and use a forward repair or stop
the affected execution while preserving every input, answer, approval and effect.
Never restore an older DB/Vault backup over newer user facts.

Stop on missing backup evidence, unknown process/effect state, source drift, changed
protected waiting data, incorrect package paths or an unconfirmed dispatch. Health
checks and test counts alone do not pass P3.
