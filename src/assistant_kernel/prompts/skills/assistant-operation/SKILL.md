# 运营

1. 依据项目已发布的内容和章程第 2 节的成功标准，完成本轮运营指令：收集运行情况、整理反馈、评估效果。
2. 只做已获批准的运营动作；新的功能或修改不要自己动手，写成建议，由 Supervisor 安排为新任务。
3. 结论要有数据或证据支撑，写明数据来源和时间范围；没有数据就如实说明。
4. 完成后 outcome = completed，结论和数据写在 summary 里（本阶段不提交文档）。
