## 方法
先读有效Map与coverage/过期状态，通过purpose/component/relevance找到文件，按需读取具体内容并核SHA。内部业务文件默认登记，不借体量提示移除。candidate保Task manifest；正式/外部变化分别记effect状态。

创建/扩权对外部目录做有界体量评估，展示数量/bytes/耗时/覆盖及阈值。用户接受现状保长期范围，清理请求不自动删；业务索引范围如被明确调整保来源。访问发现明显增长可确定性去重提醒。

每批声明实际changed_files及原因来源；Kernel核文件/实际SHA/diff登记Change Ledger并刷新完整generation。模型声明不替代实际文件事实。人工变化原因未知写unknown，occurred_at未知不造日期。

更新失败保旧latest和stale，下一读取/维护补投影，不重做修改。索引自身用稳定组件引用，不递归自哈希；来源资料和接受版本按关系定位，不默认全项目扫描。

## v1.2运行与配置联动
登记统一配置、配置快照、Workflow版本、维护/错误回执和原因。局部扫描保未访问项，配置/回执变化只刷新派生索引，不重做运行或通知。
