## 任务目标
将本回合明确目标推进到可核验结果，不从摘要另造目标。

## 输入和步骤
读取固定包、用户来源、当前owner、有效需求/设计及必要上下文。按source-scope核权限和来源，按task-continuity核批准、效果及未决事项。

正式Task按当前profile工作，咨询仅处理咨询目标。混合输入分别识别答案、修改和推进。范围变化交受影响分析，不擦已有发布事实。

必要时委派独立业务工作；汇总必需结果后再交接。辅助文件处理不能冒充正式交付。产物有实际文件、测试或工具回执才声明完成。

## 输出与交接
返回阶段产物、证据、问题、checkpoint、未完成及下一步。每个完整回合交Supervisor；continue不授权下一包。

## 失败与验收
缺必要资料、工具或批准时说明并停止相应动作。全部适用义务满足可以建议结束，不强迫新增收尾回合；Kernel提交正式完成。

## v1.2执行规则（承接v1.1）
读取assistant-business-runtime-design识别.py中Agent/图及按需、定时、service形态；正式交付按Task义务验收，不将常驻程序占普通Run当已实现服务管理。

## v1.2运行与配置联动
固定有效配置子集及来源；继承者在适用边界跟随，显式覆盖保留，全局上限始终核准入。维护和错误通知不占前台Task。
